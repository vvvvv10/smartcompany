概览 服务与架构 客户端 部署与安全 网关设计

企业工作台

Spring Cloud Gateway 统一入口 + 用户中心 + 四个业务域（CRM / TMS / WMS / OMS）， 配套 Web 管理台与移动端工作台。面向 10–50 个服务的中小规模内网系统。

模块一览

gateway

路由转发、令牌校验、身份与租户头注入、限流。不碰数据库。

:8080 · /api/**

user-center

注册登录、用户与租户、权限体系、审批、团队与组织、运营看板。

:8081 · /api/{auth,users,admin}/**

crm

客户、联系人、商机、跟进记录；个人工作台与团队看板。

:8083 · /api/crm/**

tms / wms / oms

运输订单与派车推荐、仓库库存与出入库、款号商品与多渠道订单。

:8084 / :8085 / :8086

web-console

Web 管理台：用户、租户、团队、角色权限、审批、集成配置。

React + Vite

workbench-antd

移动端工作台（定版客户端），带触感、吸顶页头、错误可重试。

antd-mobile + Capacitor · Android

请求链路

客户端 → 网关 AuthGlobalFilter(order=-100) → 业务服务 → MySQL / Redis
  1. 剥离伪造：无条件下掉客户端带来的 X-User-Id / X-Tenant-Id / X-User-Roles。
  2. 校验：白名单与 CORS 预检放行，其余必须带有效 Bearer 令牌（网关本地验签 + Redis 吊销黑名单）。
  3. 注入：把校验出的身份写回同名请求头——下游只信网关写入的值。

网关不做数据权限；能不能看某条数据由业务服务在自己的库里判定。

快速开始

后端

export MYSQL_HOST=127.0.0.1 MYSQL_PASSWORD=...
export JWT_SECRET=...        # ≥ 32 字节，gateway 与 user-center 必须一致

cd user-center && ./mvnw spring-boot:run     # :8081
cd gateway     && ./mvnw spring-boot:run     # :8080

移动端

cd workbench-antd && ./build.sh
# 单测 → tsc + vite 构建 → cap sync android → gradle assembleDebug

部署

镜像 tag 不变时必须 docker compose up -d --force-recreate <svc>，否则容器不会重建。 完整手册见仓库里的 deploy/DEPLOY.md。

凭据不入库。需要时 cp deploy/.env.example deploy/.env 自行填写； .env 与签名密钥库已在 .gitignore 中排除。
